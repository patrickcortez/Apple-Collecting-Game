# Contribution

To contribute to the development of the game, the following
must be followed:
	
	1. If you are new, Fork the repository.
	2. Ensure to consult me before working on anything.
	3. Document code changes.
	4. Ensure Implementation is clean and well documented.
	5. Changes made must not break existing features.
	6. Create a pull-request entailing why the changes were made.
	7. Always ensure your fork is upto-date w/ main.
	
**Note**: Minimize the use of *AI*, if *AI* was used. Please disclose your usage
of AI.
